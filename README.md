# Telegram Bot for Lead Qualification and CRM Handoff

## О проекте

Этот проект представляет собой Telegram-бота для первичной квалификации клиентов в сфере недвижимости.
Бот помогает переводить входящий трафик из Telegram в структурированные лиды для отдела продаж: собирает ключевые данные о пользователе, определяет интерес, сохраняет историю взаимодействия и передаёт заявку в CRM.

Проект решает не только задачу общения с пользователем, но и поддерживает маркетинговую воронку целиком: от перехода по UTM-ссылке до передачи контакта менеджеру и дальнейшей аналитики.

## Бизнес-задача

Бот автоматизирует первый этап работы с потенциальным клиентом:

- выявляет интерес пользователя;
- задаёт уточняющие вопросы по сценарию;
- собирает контактные данные с согласия пользователя;
- формирует лид в базе данных;
- передаёт заявку в Bitrix24;
- сохраняет источник трафика и путь пользователя внутри сценария;
- даёт команде продаж и маркетинга инструменты для аналитики и последующей коммуникации.

## Основные сценарии

В проекте реализованы несколько пользовательских веток:

- недвижимость для инвестиций;
- недвижимость для жизни;
- запрос аналитики доходности;
- запрос связи с менеджером;
- подписка на дальнейшие обновления и предложения.

В зависимости от сценария бот собирает и сохраняет такие данные, как:

- сегмент интереса;
- бюджет;
- срок принятия решения;
- формат управления объектом;
- инвестиционный опыт;
- номер телефона;
- UTM-источник;
- путь пользователя по этапам диалога.

После завершения сценария пользователь получает релевантный ответ или материал, а менеджер получает структурированную заявку для дальнейшей работы.

## Что автоматизировано

Проект покрывает сразу несколько прикладных процессов:

- учёт пользователей и их активности;
- хранение лидов и их статусов;
- фиксация переходов по UTM-ссылкам;
- интеграция с Bitrix24;
- работа с OpenLines;
- административная статистика по лидам и трафику;
- экспорт лидов и кликов в Excel;
- рассылки по базе пользователей;
- история сообщений между пользователем и администратором.

## Ценность для бизнеса

Этот бот выполняет роль цифрового входного слоя между рекламным трафиком и отделом продаж.
Он снижает ручную нагрузку на менеджеров, ускоряет обработку первичных обращений, повышает качество входящих лидов и делает более прозрачной аналитику по источникам трафика и конверсии.

Фактически проект объединяет в одном продукте:

- лидогенерацию;
- первичную квалификацию;
- CRM-интеграцию;
- маркетинговую аналитику;
- инструменты удержания через рассылки и подписку.

## Технический профиль

Проект реализован как backend-приложение на Python.
Основной стек:

- `aiogram`;
- `SQLAlchemy`;
- `PostgreSQL`;
- `Alembic`;
- `FastAPI`;
- `Bitrix24` / `OpenLines`.
